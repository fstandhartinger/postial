# Share and manage client approvals

Let a client review a post through a private link without creating an account.

## Steps

1. With Agency access, compose a post, select channels and a schedule, and request client approval.
2. Open [Approvals](/app/approvals), find the post and copy its link. A draft needs a saved approval request before a link can be shared.
3. Share the link privately with the intended reviewer; anyone holding it can access its review page.
4. The reviewer sees the brand and post preview, including text, images, link and schedule, and channel names. They enter their name to approve or request changes; a comment is required for a change request. The latest reviewer name and comment are visible on the review page.
5. Read the latest decision and comment in Approvals. Edit requested changes and save, then ask the reviewer to review again.
6. Use Regenerate link if a link was exposed or should be replaced, then share the new link; the old one is revoked, while previous decisions remain in history.

Approvals are grouped into Awaiting, Changes requested, Approved and Published. Drafts appear under Awaiting; exact publishing and failure statuses remain visible under Approved. A client reviewer does not consume a team seat.

Approval permits publishing at the scheduled time; it is not proof that the network received the post. Saving content edits resets approval. Date-only rescheduling preserves it. Links cannot be regenerated for published or other non-reviewable posts; started publishing attempts can also prevent changes.
