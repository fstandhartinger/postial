# Use Postial with n8n

This is the short entry point. The complete, field-by-field workflow is in the [n8n workflow guide](/docs/n8n-postial). It covers the native Postial node, the signed trigger, the HTTP Request alternative, approvals, scheduling, retries and the connected networks.

For the API and webhook contract, see [API and webhooks](/docs/api-webhooks). For the complete endpoint reference, see the [REST API reference](/docs/api).

## Steps

1. Read the [n8n workflow guide](/docs/n8n-postial) for the native node and HTTP Request setup.
2. Use [API settings](/app/settings/api) for an Agency API key and the scopes your workflow needs.
3. Inspect the created post and its per-channel status before treating a workflow run as published.
